Ether console is not built

The server and API (/ether/api/) are running, but this binary was compiled without the web console.

Build the console with Node 22+ and pnpm, then recompile Ether:

make web && make build

Or directly:

pnpm --dir web install --frozen-lockfile && pnpm --dir web build && CGO_ENABLED=0 go build ./cmd/ether
