# Ether v0.3.6

> **Draft — not released.** This describes changes in the current integration candidate. Final upgrade, performance, device and UI checks are still outstanding; the feature list and limitations will be reconciled with the release commit before publication.

Highlights:

- **Live TV stability:** buffered recovery, better handling of provider interruptions and format changes, and a fix for Plex Web's Firefox playback failure.
- **A smaller working catalogue:** database and browsing changes reduce repeated metadata reads and keep frequently used titles separate from the searchable long tail.
- **More control over IPTV:** refresh a source when clients return, with a cooldown, and choose a smaller Plex lineup while keeping channels available to external IPTV apps.
- **More Play Version choices:** an optional mode offers alternatives at each available resolution, with Auto still first and existing profile limits preserved.
- **Language and subtitle improvements:** regional and script preferences, safer audio matching during failover, and authored ASS subtitle and font delivery for Silo.
- **Collections:** 106 built-in templates, starter bundles with previews, and support for larger MDBList lists.

## Live TV and IPTV

- **Stability presets.** Choose **Fastest**, **Balanced** or **Rock solid** for the server, with a per-channel override. Larger reserves trade some distance from the live edge for more tolerance of provider interruptions.
- **Recovery within the current session.** Live playback handles reconnects, missing segments and audio/video format changes on an Ether-owned timeline. When the stable playback path becomes available, an eligible direct session can move to it without asking the viewer to tune again. Recovery may briefly show the configured reconnect screen.
- **Provider capacity is released when playback ends.** Closing an output frees its reservation so another channel can start. Reconnect and backup-source work retain the provider's connection limits.
- **Plex Web on Firefox.** Live DASH exposes separate audio and video tracks, avoiding the capability-check failure in Plex Web's bundled player ([#383](https://github.com/braedonsaunders/ether/issues/383)). This was reproduced and checked with the exact Plex player library; physical Plex apps still need their own checks.
- **Refresh when viewers return.** IPTV source settings combine a scheduled refresh interval with an optional activity-triggered refresh and minimum cooldown. Concurrent requests share refresh work. External apps read Ether's stored lineup and guide; a refresh can run in the background, so the first request may still receive the previous good snapshot.
- **A separate Plex lineup.** **Show in Plex** controls whether an enabled channel is published to Plex. Hide a channel from Plex while keeping it available through external IPTV apps. Source group exclusions and viewer restrictions still apply. Provider groups are retained in the external channel listings.
- **Guide imports update changed programmes** instead of rewriting every row on each refresh. A failed source refresh retains the previous good data.
- **Guide browsing** adds a programme inspector and multi-day navigation. AI channel matching continues past an individual invalid model reply rather than abandoning the whole batch.
- **Channel logos** have authenticated Android URLs and an external-guide fallback when the primary logo fails. Thanks to @drondeseries for [#387](https://github.com/braedonsaunders/ether/pull/387). The separate iOS and Fire TV reports in [#391](https://github.com/braedonsaunders/ether/issues/391) are not yet confirmed fixed.
- Virtual-channel break-return graphics remain visible when programme artwork is missing.

Limits: reserve buffering cannot repair an indefinitely unavailable provider. Actual Apple TV, Fire TV and external IPTV app checks on the combined release candidate remain outstanding.

## Catalogue, Home and database work

- **Less repeated work while browsing.** Library totals, popularity pages, franchise counts, Continue Watching, people searches and portrait permissions use smaller or batched reads. Stremio search loads the facts needed for its result cards instead of full credits for every candidate.
- **A working catalogue and searchable long tail.** The catalogue separates retained title details from less frequently used entries, with a file-backed search index for the long tail. Existing title identities and viewer history are preserved by the migration design. Large-library upgrade acceptance is still a release blocker; this draft does not claim a proven migration time or final database size.
- **Search ranking** gives better weight to established titles and original names, and avoids an obscure exact namesake automatically displacing a well-known title beginning with the same words. Integrated relevance measurements remain pending.
- **Background catalogue writes** batch related updates, avoid reloading just-written metadata and keep rank maintenance coordinated with catalogue migration. The remaining checkpoint admission failures must be corrected before release.
- **Collection paging** calculates pages from the titles admitted to the collection, addressing short pages and repeated continuation items reported in [#285](https://github.com/braedonsaunders/ether/issues/285). The corrected HTTP flow passes offline checks; the reported client still needs verification.
- **Partially watched titles** appear in viewer overview and recent activity, including resumed playback and rewatches ([#390](https://github.com/braedonsaunders/ether/issues/390)). This changes activity reporting, not the rules for marking a title watched.
- **Posters** have shared fallback handling and batched authorization. Native Stremio rendering of generated fallback posters remains unverified.

## Playback and Plex apps

- **Optional alternatives at every resolution.** Enable **Offer alternatives at every resolution** in the version-menu settings to distribute the alternatives count across available resolutions, up to seven versions total. Auto stays first. Existing profile, device, availability and release-ranking rules still apply, and today's version-menu behavior remains the default.
- **Plex for LG** receives a stable Auto version, addressing the loading-circle report in [#375](https://github.com/braedonsaunders/ether/issues/375). Requests that omit a version index select Auto instead of failing a multi-version decision.
- **Plex desktop downloads** are advertised to compatible desktop apps, with file-availability reporting and download-status handling ([#365](https://github.com/braedonsaunders/ether/issues/365)). Plex account entitlements and the app's own download support still apply.
- **More accurate seeking.** Copy-stream timelines use complete packet samples and keyframe information. The checked long-GOP Plex seek case now resumes near the requested position instead of jumping several seconds away.
- **Compatible audio stays copied** when the chosen output container and device support it, avoiding conversions caused by applying HLS-only restrictions to other outputs ([#376](https://github.com/braedonsaunders/ether/issues/376)). Native Apple TV HLS converts MP3 where required for playback.
- **HLS bandwidth and recovery** have corrections for encoded bursts, single-quality streams, damaged input and timestamp discontinuities. Standalone Plex encoder start and stop now use shared session ownership.
- **Remote connection addresses** retain the configured public host and scheme when away from home, with corrected reachability checks ([#381](https://github.com/braedonsaunders/ether/issues/381)).
- **Plex account watch sync** connects with the viewer's own Plex account, supports directional synchronization and respects Plex's watch-sync eligibility. It is separate from synchronizing with a connected Plex Media Server. Shared-account eligibility reports remain open.

Limit: an overloaded software encoder can still stall. In the recorded 4K60-to-1080p test with eight competing CPU workers, playback started in 15.3 seconds and stalled for 10.1 seconds. The quiet-host case passed; this is not a guarantee for overloaded hosts or untested GPUs.

## Languages and subtitles

- **Regional and script preferences** distinguish choices such as Latin American and European Spanish, Canadian and European French, and Simplified and Traditional Chinese, with fallback to related language tags.
- **Track titles help identify missing languages** when a track's language metadata is absent or undetermined. Existing valid language metadata takes precedence.
- **Safer track matching during failover.** A normal dialogue track cannot silently become commentary or audio description. Intentionally selected special tracks retain their role, and forced subtitles are not silently replaced by a full subtitle track.
- **Authored ASS and embedded fonts for Silo.** Subtitle resources use the authenticated playback session and current source. Embedded fonts can be filtered to the families referenced by the subtitle styles. Incomplete extraction returns an error rather than presenting a partial subtitle as complete.

Limits: authored subtitle rendering and font selection still need actual-client verification. Automatic preferred-language subtitle downloading is not enabled in this candidate; its backend foundation does not establish safe late-track selection in Plex, Jellyfin or Silo. The Android TV subtitle-download playback error in [#389](https://github.com/braedonsaunders/ether/issues/389) remains under investigation.

## Collections and quality profiles

- **106 collection templates** cover streaming originals, awards, seasonal collections, franchises and other curated lists.
- **Starter bundles** preview which collections will be created or skipped before applying a group. Existing collections are retained rather than duplicated. Starter selections are also available during setup.
- **Larger MDBList lists** are fetched in pages with duplicate removal. Interrupted or repeated pagination is reported rather than silently accepting a truncated list.
- **Movie and show profiles** no longer acquire duplicate per-media copies when settings reload. Older shared profiles migrate correctly on PostgreSQL ([#366](https://github.com/braedonsaunders/ether/issues/366)).
- **Russian season and episode names** no longer cause a season's release year to be mistaken for the series premiere year ([#335](https://github.com/braedonsaunders/ether/issues/335)). Unknown release resolution still follows the profile's conservative minimum-resolution policy.

## Sources and streaming

- **Usenet source-speed decisions** require multiple reads, respect the grace period and avoid replacing a stream with useful playback buffer. Speed-triggered HLS replacements must remain copy-compatible; exhausted adaptation retains the viable current source ([#385](https://github.com/braedonsaunders/ether/issues/385)).
- **Read-ahead work shares a bounded budget** across memory and disk paths and remains cancellable. Cache-inclusive delivery measurements are kept separate from fetched delivery data; neither is presented as raw network throughput.
- **Pure-Go SIMD decoding** accelerates supported yEnc paths while retaining pure-Go builds.
- **Completed searches are retained** when playback starts from an early result, preventing a timing race from discarding the final answer.
- **Stremio add-on playback** opens one selected stream link per Play rather than opening several alternatives speculatively.

Limit: the real-provider throughput and concurrent-viewer fairness checks for #385 remain outstanding. No specific download-speed improvement is claimed.

## Owner console and updates

- **Database health** uses a compact status pill alongside **Database check**, with detailed recovery guidance when a problem is found. The manual compaction control has been removed.
- **Automatic updates default on for new installations.** Existing installations retain their saved choice; an older configuration without this setting remains manual.
- Backup settings include Live TV media. The new collection, IPTV and preference controls follow the console's translated-copy conventions; full template-text translation and final UI review are still pending.

## Upgrading and draft limitations

- Back up the data directory, `config.json` and `.credentials-key`, plus PostgreSQL if used, before upgrading. Final upgrade instructions and measured space requirements will be added after the migration checks pass.
- **Do not deploy this draft as an accepted release.** The corrected SQLite upgrade measurement still rejected writes and touches. Safe automatic conversion of older databases is not finished, and no large-scale upgrade success is claimed.
- The final combined build, vet, tests, web checks, packaging checks and device round have not run. Earlier branch results do not certify this complete candidate.
- New UI still requires owner screenshot approval and review on the integrated development server. Unverified client reports are not closed by inclusion in these notes.
- Features still on unintegrated branches are omitted from the change list. This file will be updated as those changes are reviewed and accepted.
