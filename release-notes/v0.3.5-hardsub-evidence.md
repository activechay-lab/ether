# v0.3.5: hardcoded subtitles and release rejection

Based on release/0.3.5 at 8ddac1937. Branch: fix/035-hardsub-releases.

## Behavior and investigation

Indie's report does not identify which queue UI they used. The relevant paths are:

- Console Releases block: `resolver.Block`; previously remembered only release ID.
- Console Cache Clear and block: `app.clearBlockCache`; now preserves title associations from persisted playback records even after search memory expires.
- Plex `DELETE /downloadQueue/{queue}/items/{item}`: previously only cancelled and cleaned up. Now retains the exact selected release on the queue item and rejects it for its title when removed.
- Plex `DELETE /playQueues/{id}/items/{item}`: removing the selected item now rejects its active or remembered source. Removing unplayed, nonselected items and clearing upcoming items creates no rejection.
- Unpin means stop forcing a choice; it remains separate from rejecting a release.

Exact IDs, source descriptor SHA-256, infohashes, GUIDs and normalized base names match rejections. A matching release group plus the same 64 MiB size bucket also matches. Empty identities never match. Rejections apply to a title across viewers, persist in SQLite/PostgreSQL, and guard resumed/warmed sources and alternates. Owner Unblock restores the original rejection and its duplicate family. Existing exact owner blocks retain their existing global scope.

Name tags include HC, HARDSUB(S), HARDSUBBED, HARDCODED, KORSUB, CHSUB/CHS, CHT-SUB, ViE-SUB, Subbed, SUB.ITA and HC-HDRip. HDTC/HDCAM/CAMRip are conservatively treated as suspect too. Token boundaries protect Subtitles, SUBPACK, MULTISUB and ordinary word fragments.

Known or detected burned-in subtitles become last-resort candidates; an explicit `sub` exclusion prevents even last-resort playback. `sub` also covers the hard-subtitle name aliases. Other blocked keywords match complete token sequences with punctuation treated as separators. Soft subtitle tracks are not rendered into the detection frames (`-sn`). Console guidance is translated in all 20 locales.

## Content probe

Runs at the existing playback probe boundary over Ether's loopback media URL. Four grayscale 640x360 frames at 10%, 30%, 55% and 80% of min(duration, 300 seconds). Pure Go connected-component analysis requires glyph-sized bright components with dark outlines, repeated text lines in top/bottom bands in at least three samples, changed text shape and a changed central scene. Static logos are rejected by shape persistence. No OCR or external subtitle service.

One detector per transcoder manager, one decoder thread, one filter thread, eight-second total deadline, 1.5-second I/O timeout. Failed, cancelled or concurrency-skipped probes remain unknown and can retry. Successful verdicts are persisted by release ID and shared across titles/viewers; cluster hints invalidate local verdict/rejection caches. Only nonempty fetched descriptors receive source hashes.

## Offline fixture measurement

Generated with bundled Jellyfin ffmpeg using drawtext and subtitles filters. No downloaded films or live providers. Each fixture has changing scenes and, where relevant, changing dialogue.

| Fixture | Expected | Detected | Four-frame time |
| --- | --- | --- | --- |
| Clean testsrc2 | Clean | Clean | 216 ms |
| Burned SRT through libass | Burned | Burned | 220 ms |
| Static station logo | Clean | Clean | 250 ms |
| Clean grid/edges | Clean | Clean | 194 ms |
| Bottom white dialogue | Burned | Burned | 213 ms |
| Top white dialogue | Burned | Burned | 275 ms |
| Dual top/bottom dialogue | Burned | Burned | 167 ms |
| Yellow dialogue | Burned | Burned | 224 ms |

False positives: **0/3 (0%)**. False negatives: **0/5 (0%)**. This small synthetic set verifies the implementation, not field accuracy on arbitrary films. Sparse dialogue outside the four sample times, very small/dark/unoutlined text, stationary scenes, and non-band subtitles can be missed. Changing on-screen captions can resemble subtitles. Unknown detection does not revoke otherwise eligible playback. The default retains the last resort; owners can make detected hardsubs a strict exclusion with `sub`.

Reproduce with a local ffmpeg containing drawtext and libass:

```sh
ETHER_HARDSUB_FIXTURES=1 ETHER_FIXTURE_FFMPEG=/path/to/bundled/ffmpeg go test ./internal/transcode -run TestHardsubFixtures -v -count=1
```
