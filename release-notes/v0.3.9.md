# Ether v0.3.9

Highlights:

- **Jellyfin Web, served by Ether.** Turn on Jellyfin under **Apps** and Ether fetches the official Jellyfin Web 12.4 build once (pinned and checksum-verified), so a browser at `http://<server>:8096` gets the real Jellyfin web app. It is also the app inside Jellyfin for Android and the other wrapper clients.
- **Choose a version in Jellyfin and Emby apps.** A movie or episode now lists **Auto** plus Ether's top ranked releases (for example `2160p WEB-DL HEVC · DD+ 5.1 · 18.7 GB`) in the app's version picker. Auto also skips a release that would force a video transcode on that device when another ranked release can play directly.
- **New integrations:** SubDL subtitles, SkipDB intro/credits timestamps, and Zilean as a torrent source.
- **Play Version always offers a lighter source** ([#309](https://github.com/braedonsaunders/ether/discussions/309)). Turn on **Offer each source at every resolution** and Play Version keeps one WEB-DL, Blu-ray and Remux at each resolution when they exist, so a remux-first profile still offers a lighter WEB-DL. Auto is unchanged.
- **Plugin libraries in every app.** Plex shows plugin music as artist → album → track and plugin photos as albums and photos, Jellyfin and Emby use the library type the plugin declares, and Stremio gets one catalog per published library. Each plugin library has the same per-app **Show in apps** switch as your own filter libraries.
- **Plugins can transcode and speak their own protocols.** Plugin video and audio go through Ether's normal playback pipeline (direct play when the app can, transcode when it can't, stream limits included), and a plugin can serve its own app protocol, such as OPDS or Subsonic, behind Ether's sign-in.
- **Step aside for titles on your own Plex server** ([#418](https://github.com/braedonsaunders/ether/discussions/418)).
- **A quality profile per library** ([#419](https://github.com/braedonsaunders/ether/issues/419)). Set a profile on any library under its **Settings**, and titles in it rank with that profile everywhere they appear — make an Anime library from a filter, import a TRaSH or Dictionarry anime profile, and set it there. Client rules and the Away profile still win, and **Default** keeps today's Movies/Shows behaviour.
- **Plex Web plays again when a title needs converting** ([#432](https://github.com/braedonsaunders/ether/issues/432)), and fixes for LG and Samsung TVs, Android subtitles, Jellyfin for Roku and wrong cast on Plex TV apps.

## Plugins

- **Stremio add-ons hosted on GitHub work.** A static add-on installed from its GitHub repo link (USA TV Next, for example) was treated as a plugin needing a sidecar and failed with "no sidecar connected". Ether now reads it straight from GitHub's raw files, like Stremio does. Every kind of add-on (hosted, configured, `stremio://`, `/configure` links, GitHub, raw and LAN) was swept end to end: catalogs, search, metadata, streams, subtitles, Live TV channels and add-on catalogs.
- **Sidecars install like an app.** A plugin that runs as its own program (on a NAS, another site, or anywhere Ether's sandbox can't reach) now shows **Waiting for its sidecar** until it connects. **Connect a sidecar** gives a ready command with your server and a one-time code filled in: `docker run …` when the developer publishes an image, or a download link and start command. The program pairs itself, saves its credential so restarts need no new code, and stops cleanly with one plain line if you revoke it. The Go, Python and TypeScript SDKs do all of this built in (`ETHER_URL`, `ETHER_PAIRING_CODE`), and a manifest's new `sidecar` block tells the console what to show.
- **Plex music and photo libraries.** A plugin library declared as music lists as an artist section, opens artist → album → track, and plays tracks; a photo library opens albums and photos. Movies and TV Shows are unchanged.
- **Jellyfin, Emby and Stremio.** Plugin libraries show with their declared type (music, audiobooks, books, photos, home videos, movies, TV). Stremio lists a catalog per published plugin library.
- **Show in apps, per library.** The console's plugin library settings now show the real per-app publishing switch; the "Only in this console" note is gone.
- **Transcoding for plugin media.** Plugin video and audio items are probed and played like your other titles: direct play when the app supports the file, a transcode when it doesn't, with your stream limits and the viewer's chosen audio and subtitle tracks.
- **Protocol adapters.** A plugin can mount its own app protocol. Ether signs the viewer in first, the plugin never sees an Ether credential, libraries a viewer can't see answer as not found, and media plays through short-lived Ether links (`StreamURL` in the Go, Python and TypeScript SDKs). The SDKs pass the adapter every HTTP method (WebDAV's PROPFIND, HEAD, PUT…) and the original query string, so Subsonic and OPDS search work ([#440](https://github.com/braedonsaunders/ether/issues/440)).

## Jellyfin and Emby apps

Tested end to end on Jellyfin Web, Jellyfin for Android, Findroid and Streamyfin, with responses checked against real Jellyfin 12.4 and Emby 4.10 servers.

- **Jellyfin for Android plays.** Its native player signs requests differently from its web layer (a longer device id, `+` for spaces). Ether refused those requests, so playback never started. They are now accepted, the same way Jellyfin does.
- **Findroid plays.** Findroid's player fetches the video without credentials. Ether now serves that request when it matches a session the same device just opened, and Findroid's "Index 0 out of bounds" error is gone.
- **Streamyfin plays.** "No compatible stream" when the app asked for the default audio track is fixed.
- **Artwork on wide rows and the spotlight** ([#405](https://github.com/braedonsaunders/ether/issues/405)). Lists now carry backdrop, thumb and logo tags like Jellyfin does (apps can still narrow them with `EnableImageTypes`), so Moonfin's home-screen spotlight and wide rows show their art instead of blanks.
- **Played episodes in an instant** ([#405](https://github.com/braedonsaunders/ether/issues/405)). A "recently watched episodes" row (Moonfin asks for it on every launch) walked every show and season in the library and timed out after 15 seconds on large libraries. It now reads straight from the viewer's watch history, newest first, so it costs the same for 10 shows or 10,000. Jellyfin and Emby apps can also sort by **Date played**.
- **Live updates in packaged TV apps** ([#405](https://github.com/braedonsaunders/ether/issues/405)). Apps that send `Origin: null` (Moonfin on TVs) were refused the live-update socket, so remote control and play-state sync never arrived. The socket now accepts them, as Jellyfin does; it was already authenticated by the app's token.
- **Faster start with Auto.** Ether no longer opens the release Auto is about to skip. A Findroid start that took 8.7 s now takes 1.5 s.
- **More of the Jellyfin and Emby API.** `/Items?Ids=`, `/Years`, `/UserItems/{id}/UserData`, `/Audio/{id}/stream`, `/Sessions/Playing/Ping`, item collections, the Live TV folder and richer session and system info are now served. Emby lists carry media sources, and items carry their streams and subtitle flags. Unknown views and plugin-library favourites answer empty instead of erroring.

## Plex Media Server sync

- **Step aside for titles on this server.** Each server under **Integrations › Plex Media Server sync** has a **Step aside for titles on this server** switch (off by default) that hides movies, complete shows and episodes that server already holds from Plex apps, while keeping partially held shows visible for missing episodes. Jellyfin, Emby and Silo are unaffected, and titles already in progress on Ether are preserved.

## Fixes

- **Plex Web: "This server is not powerful enough to convert video"** ([#432](https://github.com/braedonsaunders/ether/issues/432)). Since 0.3.8, Ether's server information told Plex Web it had no transcoder, so Plex Web refused anything it couldn't play directly without asking Ether. It now reports the transcoder correctly.
- **Plex for Samsung** ([#424](https://github.com/braedonsaunders/ether/issues/424)). Samsung's built-in player requests media with only a token and no app headers; those requests are now served and counted as a session instead of being refused.
- **Plex on LG TVs** ([#434](https://github.com/braedonsaunders/ether/issues/434)). Since 0.3.8, LG's player stopped on a loading circle or an error when a transcode sent an empty video fragment. Those fragments are now well-formed.
- **Embedded subtitles on Plex for Android** ([#191](https://github.com/braedonsaunders/ether/issues/191)). Subtitles that have to be burned into the picture now stay on when the app asks for no separate subtitle stream.
- **Wrong cast and art in Plex TV and mobile apps** ([#430](https://github.com/braedonsaunders/ether/issues/430)). A title could inherit the Plex identity of a different film with the same name (for example *Runner* 2026 and *Runner* 1962). Ether now attaches a Plex identity only when its TMDB id, title, year, director and cast agree, and re-checks the ones already stored, namesakes first.
- **The wrong film for a shared title.** When two films share a name, playback now refuses a release whose running time doesn't match the title you picked, so *Runner* no longer plays *The Runner*.
- **Jellyfin for Roku and slow Jellyfin listings** ([#421](https://github.com/braedonsaunders/ether/issues/421)). A Favorites row no longer walks every season of your TV library, which also stopped sign-ins timing out behind it; the series and season **Resume** button works.
- **Linking Plex when your Plex account was already a viewer.** If you set Ether up with a local owner account and your Plex account had already signed in as a viewer, linking Plex now merges that viewer's history into the owner instead of failing.
- **One Piece and other long anime play again** ([#439](https://github.com/braedonsaunders/ether/issues/439)). TMDB splits some anime into story-arc seasons that keep absolute episode numbers (One Piece season 18 is episodes 749–803). Ether counted those numbers twice (749 became 1497), so it searched for and matched an episode that doesn't exist. Arc-season episodes now keep their absolute number.
- **Spanish and Portuguese season tags.** Release names like `Serie.T07E09` are read as season 7, episode 9.
- **Live TV fallbacks move forward** (by @activechay-lab). When a channel's next programme can't start, the stand-in is now always something scheduled at or after that slot, never a replay of the programme that just aired.
- **Live TV guide artwork** (by @activechay-lab). Programme posters and backgrounds in the Plex guide now load; they were sent as raw image paths the apps couldn't fetch. Episodes show their series' artwork.
- **Live TV show sources start at season 1** (by @activechay-lab). A new show source now saves season 1, episode 1, so a channel no longer quietly includes season 0 specials. Weight, start season and episode, and the movie pool can now be cleared with backspace while editing; leaving an empty field restores its default, so it is never saved unset.
- **Releases with a RAR set inside another archive play** (by @javi11, [#427](https://github.com/braedonsaunders/ether/pull/427)). The inner set is read straight from the outer archive's files without extracting anything, so readahead, PAR2 checks and repair still apply.
- **NZB downloads in more formats.** Zipped, UTF-16 and byte-order-marked NZBs are accepted, and when a download still isn't an NZB the error says what the indexer sent instead (an HTML or Cloudflare page, JSON, other XML).

## AI apps (MCP)

- **Quality profile groups** (by @javi11, [#428](https://github.com/braedonsaunders/ether/pull/428)). AI apps can read a profile's quality groups, scores and language settings, and propose a new quality order through the usual approval. Grouping HD and UHD lets a language score decide between them, so "Spanish 1080p over English 4K" is reachable.

## Integrations

- **MDBList watch history** ([#436](https://github.com/braedonsaunders/ether/issues/436)). Turn on MDBList under **Integrations**, then each viewer pastes their own MDBList API key in their account. What they watch is sent to MDBList, and their MDBList history can be imported once. Like Trakt and Simkl, it runs only when there is something to send and never slows playback.

## Sources

- **Zilean.** Add a Zilean instance (the DMM hash index) under **Sources › Indexers** as a torrent source for your debrid account. It is self-hosted, so you enter its URL.
- **Nyaa.** The Nyaa.si Cardigann definition is verified end to end.
- **Let availability checks open add-on streams** ([#426](https://github.com/braedonsaunders/ether/issues/426)). A new switch on **Sources › Indexers**, off by default, lets the file-availability check that apps run on a detail page open on-demand add-on streams, within its usual time and concurrency limits. Warm-ups and other background work still never open them.

## Subtitles and markers

- **SubDL.** A second subtitle provider beside OpenSubtitles. Add your SubDL API key under **Integrations**.
- **SkipDB.** A second source of intro and credits timestamps beside TheIntroDB, used when a title's own chapters don't mark them. Turn it on under **Playback › Skip buttons**.

## Under the hood

- **Faster studio filters.** Filtering movies by a studio no longer slows down as the library grows.
- **Plex artwork colours.** Plex apps' `ultrablur` colour requests are answered from Ether's palette cache.
- **Diagnostics.** Slow-request warnings now include the request's safe listing parameters (types, sort, fields, filters), never names, ids or tokens.
- **Web console dependencies.** `ai` 7.
