# Ether v0.3.4

## Live TV

- Live TV now groups Channels, Sources and Guide in separate tabs, with a picture-backed On Now strip. The guide stays in place while you edit a channel.
- Large lineups use paged channel lists, batched imports with progress, and narrower guide requests. Bulk channel edits and source refreshes coordinate across cluster nodes.
- Xtream sources have improved account details, channel groups and guide matching. Thanks to @evulhotdog for the Live TV work in [#333](https://github.com/braedonsaunders/ether/pull/333).
- Virtual channels play a silent **Off air** card during scheduled gaps instead of failing playback. The card shows the channel and the next programme's start in the channel's time zone, on both HLS and DASH.
- Programme metadata and DVR guide identifiers better match Plex's guide format. Tune failures retain more useful diagnostic information. The Apple TV programme-details fix still needs confirmation on a physical device.

## Playback and Plex apps

- Playback recovery, timestamp handling, subtitle delivery and seeking have fixes across HLS, DASH and Matroska paths.
- Dolby Vision profile 5 to SDR conversion uses the Dolby Vision metadata, including with hardware encoding. Compatible HDR10 fallback copy streams strip Dolby Vision signaling; desktop Plex apps retain native direct play. These fixes do not yet establish that the reported Shield/LG crash in [#328](https://github.com/braedonsaunders/ether/issues/328) is resolved.
- Playback errors report clearer failure reasons, transient failures remain retryable, and an unknown duration is no longer presented as a confirmed duration.
- Download subtitle/quality selection, VAAPI subtitle burn-in, Plex for Kodi part reads and several Emby/Jellyfin client paths have compatibility fixes.
- Continue Watching refreshes, watch-position database contention and post-play selection have fixes. Regular episode playback no longer selects a special as the next regular episode.
- Plex claim changes preserve the live server identity, reject ambiguous claim input and avoid stale queued device removal. This does not establish the cause of the separate PMS claim-loss report in [#330](https://github.com/braedonsaunders/ether/issues/330).

## Owner console and integrations

- Updates shows routine backup/startup work as normal progress and reconnects automatically. Opening Updates checks for a new version, and a manual check remains available.
- Activity gains playback and delivery information, with corrected field mapping and localized formatting.
- Direct watch-state synchronization with an owner-run Plex Media Server is available under **Integrations → Plex Media Servers**. Add the server and its owner token, map viewers explicitly, and select a direction. This is separate from Plex account watch sync, which remains unavailable. Ratings and unwatches made on the PMS are not imported. Real PMS write-endpoint validation remains outstanding; see [#288](https://github.com/braedonsaunders/ether/issues/288).
- Login offers only the sign-in methods advertised by the server. Calendar empty results, settings navigation, translated labels and clipboard feedback have corrections.
- Studio retains its Describe/Code editor. The unused mock editor and development-only workbench were removed.

## Sources and reliability

- Indexer traffic and repeated NZB downloads have further reductions, and source retry work is bounded. Release-feed matching avoids scanning the whole catalogue for every page.
- Live TV probes and imports recover when the original caller cancels shared work. Metadata and guide retry delays are capped.
- Subtitle searches cache empty results briefly. TheIntroDB and Silo skip settings now apply consistently.
- Credential handling, plugin isolation, request authentication and input bounds have hardening changes.
- Shared Go helpers replace duplicated implementations. CI now exercises PostgreSQL components and requires the pinned API specifications used by conformance checks.

## Upgrade notes and current limitations

- Keep a complete backup, including `.credentials-key`, before upgrading. Existing v1 and plaintext credentials are converted to v2 at startup. Old stored watch clocks, configuration forms and broker snapshots are also converted; normal reads use the current format afterward.
- Backup uploads now require encrypted backups; the plaintext upload option has been removed.
- Physical Shield and Apple TV confirmation remains outstanding. Four Apple near-end copy seeks without a usable index remain known failures in the recorded playback matrix.
- Offline checks and CI do not establish that every reported physical-client symptom is resolved. No issue is closed solely by these notes.
