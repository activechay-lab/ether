# Ether v0.3.8

Highlights:

- **Libraries replace the Catalogue.** Movies and TV Shows are now libraries, each with its own **Browse · Rules · Settings**. Visibility rules, new-release timing and settings belong to each library, and you can add saved-filter libraries that stay console-only until you show them in apps.
- **New releases appear the moment they can play, and stay.** "When they can play" now works like Radarr: a title unlocks as soon as a verified release exists and is never hidden again. It costs next to nothing while idle.
- **Much lower memory and CPU on idle servers.** Profiling a production server found background work allocating ~24 GB an hour while nothing played; that work is gone, and Ether now sets a sensible memory limit for your machine.
- **Discs and season packs play.** Disc images (ISO, Blu-ray and DVD folders, multi-disc films) play their main feature, and single episodes stream straight out of Usenet season packs.
- **Bring your Plex people over.** Import the accounts on your own Plex Media Server as Ether viewers in a few clicks, and copy their full watch history either way ([#392](https://github.com/braedonsaunders/ether/pull/392)).
- **Live TV channels flow like real TV.** Channel graphics render live into the stream the first time and are saved for every airing after, the show is loaded during the break so it comes straight back, and nothing renders for channels nobody watches.
- **Fixes for LG, Roku, Plex for Mac and TorBox** ([#417](https://github.com/braedonsaunders/ether/issues/417), [#421](https://github.com/braedonsaunders/ether/issues/421), [#420](https://github.com/braedonsaunders/ether/issues/420), [#365](https://github.com/braedonsaunders/ether/issues/365), [#422](https://github.com/braedonsaunders/ether/pull/422), [#423](https://github.com/braedonsaunders/ether/pull/423)).

## Libraries

- **Libraries page.** Movies and TV Shows are the built-in libraries: rename, hide from apps, or reorder them. **New library** first asks where titles come from: a saved filter over TMDB (genres, years, ratings, keywords) or a plugin's catalogue.
- **Inside a library: Browse · Rules · Settings.** Browse is the catalogue browser scoped to that library. Rules are this library's visibility rules, with the live shown/hidden preview; your previous global rules were split onto Movies and TV Shows automatically, and viewer exceptions keep working.
- **Everything is set per library.** New releases timing is now separate for Movies and TV Shows. Language, region and "what's browsable" live under each library's **Source: TMDB** section (shared by every TMDB library). The separate global settings page is gone; watchlist settings moved to **Viewers**.
- **Viewer access per library.** **Viewers › Limits › Libraries this viewer can open** uses the new libraries.
- **Plugin libraries.** Plugins can declare their own kinds of media (audiobooks, comics, anything) with their own library, catalogue sync, search and streaming, and the SDKs and Studio support building them. Installing such a plugin creates its library, with a guided setup; it browses and plays in the console. Plugins that don't declare a library create nothing. Showing plugin libraries in Plex, Jellyfin and other apps arrives in v0.3.9.

## New releases

- **Unlocks on a real release, never hides again.** In "When they can play" a title appears as soon as Ether sees a verified playable release for your quality profile: a release that passed a health check, a cached debrid copy, or a successful play. An unverified listing unlocks it once the official digital or air date has passed, so pre-release fakes don't. Once a title is visible it stays visible; a bad release is just skipped.
- **Cheap at any size.** The hidden-title check is part of the normal library query (12 ms on a 50,000-title test), and an idle server does almost no work for it.

## Live TV

- **No more still screens between programmes.** A channel's transitions (ident, break, back, up next, coming up) used to air as a still card until their animation had been rendered ahead of time. They now render live into the channel's stream the first time they air and are saved for every airing after; "up next" and "coming up" save only their animated background and draw the titles live on top, so storage stays bounded.
- **Back from the break on time.** While a break airs, Ether loads the show's return point, and it loads the next programme a few minutes before it starts, so handoffs don't stall.
- **Only what someone is watching.** Rendering and loading happen only for channels with a viewer; an idle server does none of it.
- **RTX Video Super Resolution on channels:** when enabled under Transcoding, a running channel switches to it at the next segment, without restarting the stream.

## Performance and memory

- **Idle churn removed.** Re-checking preloaded cache blocks re-read every cached file in full on each pass (~18 GB an hour on a real server); it now reads an 8-byte header. Recomputing hidden titles (~6 GB an hour) is replaced by the new release gate.
- **Automatic memory limit.** Ether sets a soft memory limit at startup (90% of a container's limit, otherwise half of RAM, at least 1 GiB) and logs it. If garbage collection starts eating CPU because the heap sits at that limit, Ether raises its own limit and logs why. A `GOMEMLIMIT` you set yourself is always respected.

## Playback

- **Disc images play.** ISO 9660/UDF images, Blu-ray and DVD folders and multi-disc films play their main feature as one continuous title, including from encrypted archives.
- **Episodes from season packs.** A single episode streams from a Usenet season pack or a season held in one archive, with PAR2 verification kept.
- **LG webOS** HLS playback no longer stalls on long keyframe gaps, and resume works ([#417](https://github.com/braedonsaunders/ether/issues/417)).
- **Jellyfin for Roku** opens Films and TV instead of exiting ([#421](https://github.com/braedonsaunders/ether/issues/421)).
- **Plex for Mac:** changing quality switches to a transcode instead of continuing the original ([#420](https://github.com/braedonsaunders/ether/issues/420)), and **Download** is offered for Ether items ([#365](https://github.com/braedonsaunders/ether/issues/365)).
- **TorBox streams recover** from a dead CDN host during API cooldowns and from stalled responses ([#422](https://github.com/braedonsaunders/ether/pull/422), [#423](https://github.com/braedonsaunders/ether/pull/423), thanks @ogrrd).

## Viewers and sync

- **Import from Plex** ([#392](https://github.com/braedonsaunders/ether/pull/392), thanks @drondeseries): list the accounts on your connected Plex Media Servers, match them to viewers or add them, and share your libraries on plex.tv, keeping any existing library grants and content filters.
- **Plex Media Server Sync** (renamed from "Plex watch sync" so it can't be confused with **Plex account sync**) can **bring in** or **send** a viewer's full watch history, with a preview first and live progress.
- **Trakt per viewer:** connect any viewer's Trakt account from **Viewers › Limits**, or let viewers link their own on `/ether/me`.
- **Friends' Watchlist RSS** builds a shared "Your friends want to watch" row with availability alerts ([#337](https://github.com/braedonsaunders/ether/issues/337)).

## Apps

- **Per-app public address** ([#413](https://github.com/braedonsaunders/ether/issues/413)): each non-Plex app can publish its own outside address.
- **Automatic subtitles switch** ([#286](https://github.com/braedonsaunders/ether/discussions/286)) under **Integrations › OpenSubtitles**.
- **Plex runs on the same shared services as every other app**, so fixes made for one client reach all of them.

## Plugins

- **Uploading a plugin package works again:** installing a `.etherpkg` from the console failed at the last step.
- **Plugin text is translated everywhere:** the install preview, plugin list and setup wizard no longer show raw `$t:` keys.

## Building from source and contributors

- **Generated web console assets are no longer committed to git** ([#386](https://github.com/braedonsaunders/ether/issues/386)). Official binaries, installers, packages and Docker images still include the full console.
  - **Source builds with the console:** install Node 22+ and `pnpm` 10 and run `make build` (or `scripts/build-web.sh` before `go build ./cmd/ether`). `docker build .` compiles the console automatically.
  - **Go-only development:** `go build ./...`, `go vet ./...` and `go test` work on a clean checkout without Node.
  - **Faster clones:** `git clone --filter=blob:none https://github.com/braedonsaunders/ether.git` skips historical asset blobs. See [`CONTRIBUTING.md`](../CONTRIBUTING.md).
