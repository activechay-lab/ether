# Ether v0.3.8

## Performance

- **Memory now stays bounded on small machines.** Ether sets an automatic soft memory limit at startup — 90% of the container's memory limit when one exists (Docker/cgroup), otherwise half of physical RAM (at least 1 GiB) — so the heap no longer climbs for hours on an 8 GB box and freed memory returns to the OS promptly; the startup log states the limit and where it came from. To take control yourself, set `GOMEMLIMIT` (e.g. `GOMEMLIMIT=2GiB`): when it is present Ether never overrides it.
- **Availability hidden sets now publish only what changed.** Republishing the titles held back for playable evidence used to copy the whole set every refresh, so on a large library each small evidence change held the database writer for over a second every minute or two and churned the database file. Membership is now stored as intervals and a refresh writes only the titles added or removed; an unchanged set writes nothing.

- **LG webOS HLS playback and resume** ([#417](https://github.com/braedonsaunders/ether/issues/417)): HLS fMP4 streams that copy video while converting audio no longer stall on a spinner at multi-segment GOPs (serving empty sequential fragments instead of repeating backward decode timestamps while delivering or regenerating the covering keyframe on seeks) or hang when a resume opens on a video-only preroll or audio-only chunk.
- **Per-app public address** ([#413](https://github.com/braedonsaunders/ether/issues/413)): each app (Jellyfin, Emby, and the rest) can now have its own **Public address** under Apps, so owners who route each app through its own host name (e.g. `jelly.example.com`) see that app's address on Connect and `/ether/me` instead of the Plex host. Plex keeps using its custom server URLs; an app without its own address keeps the server-wide address as before.
- **Automatic preferred-language subtitles switch** ([#286](https://github.com/braedonsaunders/ether/discussions/286)): **Integrations › OpenSubtitles** now includes a **Download a subtitle automatically when playback starts** switch (`openSubtitles.automaticPreferred`, off by default) so owners can turn automatic preferred-language subtitle downloads on or off from the console.
- **Plex Watchlist RSS import** ([#337](https://github.com/braedonsaunders/ether/issues/337)): owners can paste Plex's **Friends' Watchlist RSS** and **Your Watchlist RSS** URLs under **Catalog › Settings › Watchlists** (sealed at rest). Because Plex's friends feed does not say which friend added each title, **Friends' Watchlist RSS** builds a shared **Your friends want to watch** Home row and collection (filtered per viewer like any row) and feeds availability monitoring, alerts, and warm-up alongside the owner's watchlist.
- **Viewers can connect Trakt:** once **Integrations › Trakt** is set up, owners can connect any viewer's Trakt account from **Viewers › Limits**, or viewers can link their own account on `/ether/me` using a Trakt activation code (`https://trakt.tv/activate`) to sync watch history, ratings, and watchlists.
- **Clearer Plex watch sync:** **Integrations › Overview** now calls server-to-server sync **Plex Media Server sync** and links each mapped viewer, while **Viewers › Limits** names plex.tv sync **Plex account sync** and shows that viewer's Plex Media Server mappings in a separate read-only block.
- **Full watch-history backfill for Plex Media Server sync:** each mapped viewer under **Integrations › Plex Media Server sync** now offers **Bring in full history from this server** (when reading is on) and **Send Ether's full history to this server** (when sending is on), walking older history in pages in the background with live progress and never overwriting newer watch state on either side.

## Building from source and contributors

- **Generated web console assets are no longer committed to git** ([#386](https://github.com/braedonsaunders/ether/issues/386)). Official binaries, installers, packages, and Docker images are unchanged and include the full `/ether/` console as before.
  - **Source builds with the web console:** install Node 22+ and `pnpm` 10 and run `make build` (or `scripts/build-web.sh` before `go build ./cmd/ether`). Multi-stage `docker build .` compiles the console automatically.
  - **Go-only development:** `go build ./...`, `go vet ./...`, and `go test` continue to work on a clean checkout without Node (`GET /ether/` serves a build-instructions placeholder while `/ether/api/` and all client protocols run normally).
  - **Faster clones:** git history is preserved so existing forks, tags, and commit references stay intact; use `git clone --filter=blob:none https://github.com/braedonsaunders/ether.git` to skip historical asset blobs. See [`CONTRIBUTING.md`](../CONTRIBUTING.md).
