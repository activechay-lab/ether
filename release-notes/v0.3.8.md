# Ether v0.3.8

- **Per-app public address** ([#413](https://github.com/braedonsaunders/ether/issues/413)): each app (Jellyfin, Emby, and the rest) can now have its own **Public address** under Apps, so owners who route each app through its own host name (e.g. `jelly.example.com`) see that app's address on Connect and `/ether/me` instead of the Plex host. Plex keeps using its custom server URLs; an app without its own address keeps the server-wide address as before.

## Building from source and contributors

- **Generated web console assets are no longer committed to git** ([#386](https://github.com/braedonsaunders/ether/issues/386)). Official binaries, installers, packages, and Docker images are unchanged and include the full `/ether/` console as before.
  - **Source builds with the web console:** install Node 22+ and `pnpm` 10 and run `make build` (or `scripts/build-web.sh` before `go build ./cmd/ether`). Multi-stage `docker build .` compiles the console automatically.
  - **Go-only development:** `go build ./...`, `go vet ./...`, and `go test` continue to work on a clean checkout without Node (`GET /ether/` serves a build-instructions placeholder while `/ether/api/` and all client protocols run normally).
  - **Faster clones:** git history is preserved so existing forks, tags, and commit references stay intact; use `git clone --filter=blob:none https://github.com/braedonsaunders/ether.git` to skip historical asset blobs. See [`CONTRIBUTING.md`](../CONTRIBUTING.md).
