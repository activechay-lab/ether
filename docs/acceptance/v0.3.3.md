**Why these tests keep needing per-test fixes.** The package has no shared fixture contract. Each test builds an `App` its own way: a full `New` on a fresh directory, a hand-assembled `&App{...}`, or `store.Open` plus selected components. A full `New` starts background work (warm-ups, budgets, startup status, housekeeping) that the test then races with its assertions. That accounts for the recurring "budgets read too early", "startup status" and ID-shape fixes. Recommendation: one `testApp` builder with explicit options (seeded database, injected clock, background loops off unless asked for) and an explicit "settled" signal from `New`, replacing ad-hoc waits. Removing them would let the shards use the runner's cores instead of summing serially.

### Certificate syncs outlive the manager (RC ubuntu `rest`) — owner `thr_p7kykbjjhz`

Branch `fix/cert-manager-lifetime`. RC CI failed with `TestCertManagerSharedAcrossNodes … TempDir RemoveAll cleanup: … directory not empty`.

**Cause.** `CertManager.SetEventBus` handled every `certs:changed` and `bus:resync` event with a detached goroutine running `SyncShared` on `context.Background()` (30 s timeout). Nothing tracked it, and `CertManager` had no `Close`. A sync triggered by the leader's renewal could therefore still be writing `plexdirect.crt`/`.key` into the directory after the test returned, or for up to 30 s while a production node shut down. Separately, each file was written through a fixed-name `.tmp` with no fsync, and the key and certificate were renamed independently.

| Checkpoint | Implementation and evidence | Remaining acceptance work |
| --- | --- | --- |
| Manager lifetime and Close | `0994f21bb`: `Ensure`/`Install`/`SyncShared`/`RequireReissue` share a one-slot gate (`begin`) whose context ends with the manager's lifetime. Bus syncs and `RunSharedSync` are tracked (`sync.WaitGroup`, added under `mu` only while open). `Close` unsubscribes from the bus, cancels, waits up to 10 s and then keeps the slot, so no operation writes after it returns. Later calls return `ErrCertManagerClosed`, the served certificate stays available, and `SetEventBus` after `Close` is ignored. A cancelled shared sync no longer installs the cluster copy. Stale `.*.tmp` files are removed when the manager starts.
